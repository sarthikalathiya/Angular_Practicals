# 05_Practical

User Management System built with Angular.

## Development Server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The app will automatically reload when you change any source file.

## Code Scaffolding

Generate a new component using:
```bash
ng generate component component-name
```
For more details, refer to the Angular CLI documentation.

## Build

Run `ng build` to build the project. The build artifacts will be stored in the `dist/05-practical/` directory.

## Running Unit Tests

Use `ng test` to execute unit tests via Karma.

## Running End-to-End Tests

Run `ng e2e` for end-to-end testing (ensure you have an e2e framework configured).

## Features

- Add and list users.
- Validate unique email without clearing the form.
- Dynamic addition of departments.
